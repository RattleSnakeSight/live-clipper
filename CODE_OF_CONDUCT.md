# Code of Conduct

Be respectful. Keep discussion about the work. No harassment, insults or personal attacks.

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Maintainers may edit or remove comments, issues and pull requests that break it, and may block people who
keep doing so. To report a problem, use the repository's Security tab and mark it as a conduct report.
