# Formats and presets

A format decides which moments become clips. A preset decides how a clip looks: layout, captions, length.

Live Clipper ships a default format and preset. You can edit them, import one from a file, or export yours
to share. Rules can then change the format or preset for a particular streamer, platform, game or title.
A setting you change on a single clip always wins.
