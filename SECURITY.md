# Security

## Reporting a vulnerability

Please report security problems privately. Open the repository's Security tab and choose "Report a
vulnerability" (GitHub private vulnerability reporting). Do not open a public issue for it.

Include what you found, the steps to reproduce it and the version (`live-clipper version`). Remove tokens
and personal information from anything you attach.

## Supported versions

Fixes go into the newest version. Live Clipper itself requires the newest version to run (see the in-app
guide page Updating), so there are no maintained older versions.

## Scope

Live Clipper runs on your computer and listens on `127.0.0.1` only. Reports about the local web interface,
the secrets vault, log redaction, the install scripts and the posting adapters are all in scope.
